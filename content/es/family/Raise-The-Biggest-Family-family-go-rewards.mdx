### Elegir entre usar de inmediato y guardar

El uso inmediato es apropiado cuando la recompensa completa una mejora clara, como cumplir un requisito para el siguiente objetivo familiar. Guardarla es mejor cuando el objeto es raro, tiene muchos usos posibles o está relacionado con una condición futura desconocida.

Utiliza esta prueba de decisión:

- ¿Gastarlo completará un objetivo actual?
- ¿El objeto tiene más de un uso posible?
- ¿Es probable que otra recompensa proporcione el mismo material?
- ¿Podría el siguiente hito requerir este recurso?
- ¿Se puede revertir la compra?

Si la respuesta no está clara, guarda el objeto como reserva. Una guía de recompensas debe ayudar a los jugadores a tomar decisiones informadas, no impulsarlos a realizar gastos innecesarios.
